# **SARP - Security Assessment Repositories Project**

🚀 **SARP** é um projeto desenvolvido para facilitar a avaliação de segurança em repositórios, proporcionando uma interface simples e poderosa para realizar as análises.

---

## **📋 Pré-requisitos**

Certifique-se de ter instalado em sua máquina:
- **Python** (versão 3.7 ou superior)
- **Pip** (gerenciador de pacotes do Python)

---

## **⚙️ Como rodar o projeto**

1. Clone o repositório ou faça o download do projeto.
2. Navegue até o diretório da aplicação principal:
   ```bash
   cd assessment_app
   ```
3. Instale o Django:
   ```bash
   pip install django
   ```
4. Inicie o servidor local:
   ```bash
   python manage.py runserver
   ```
5. Acesse o projeto no navegador pelo endereço:
   ```
   http://127.0.0.1:8000
   ```
